# MicroCFO - AI-Powered Financial Assistant for Indian MSMEs

An intelligent financial operations assistant powered by AI, designed specifically for Indian Micro, Small and Medium Enterprises (MSMEs).

## Features

- **📄 Visual Auditor** - AI-powered invoice scanning with fraud detection
- **⚖️ Legal Sentinel** - GST and compliance law advisor
- **💰 Subsidy Hunter** - Discover government schemes and subsidies
- **📊 Dashboard** - Financial overview and analytics

## How to Use

1. Upload an invoice image to get it analyzed
2. Ask compliance questions about GST and tax laws
3. Discover applicable subsidies based on your business sector

## Environment Variables

Configure the following secrets in Hugging Face Spaces:
- `GEMINI_API_KEY` - Google Gemini API key for AI processing
